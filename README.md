## 📊 Portfolio Projects


#### 🌾 1. Soil Analysis for Crop Selection Using ML
- **Goal:** To build a multi-class classification model predicting crop types based on soil measures and to identify the most important nutrient feature for the model's predictive performance.
- **Description:** Analyzed essential soil metrics (Nitrogen, Phosphorus, Potassium, and pH). Built and trained a Logistic Regression model to classify crops and evaluated feature importance using weighted F1 scores, discovering that Potassium (K) had the most significant influence on predictive performance.
- **Skills:** Machine Learning, Multi-class Classification, Feature Selection, Model Evaluation
- **Technology:** `Python`, `Pandas`, `NumPy`, `Scikit-Learn`, `Matplotlib`

- **Skills:** Reinforcement Learning, Q-Learning, Epsilon-Greedy Strategy, Agent Simulation
- **Technology:** `Python`, `Gymnasium`, `NumPy`, `ImageIO`
- 🔗 **[View Notebook on Kaggle](https://www.kaggle.com/code/igwebuikeoluchi/taxi-v3-environment)**
